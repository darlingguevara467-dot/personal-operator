description: Catch up after being away — one short digest of what happened, what got done, and what needs you.
---

The user is back. Run the `daily-brief` skill, scoped to the time since they went `/away` (or the last 24 hours if there was no away window).

Put **Needs you** first, numbered, so they can answer by number ("1 yes, 2 no").

Then list what was done (calls with outcomes and confirmation numbers, drafts waiting in Gmail), then today's calendar, then the inbox counts.

End with one line: the single most useful next step, if there is one.
